# Lead Qualification Agent

An AI-powered lead qualification project that evaluates and scores leads based on defined criteria to help prioritize potential customers.

## Features
- Lead scoring and qualification
- Configurable agent settings
- CSV-based lead input
- Qualified lead output in JSON format
- Automated scoring tests

## Tech Stack
- Python
- CSV and JSON
- Pytest

## Project Structure
- `app.py` – Application entry point
- `src/agent.py` – Agent logic
- `src/agent_config.py` – Agent configuration
- `src/scoring.py` – Lead scoring logic
- `data/` – Sample lead data
- `output/` – Qualified lead results
- `tests/` – Test files

## Getting Started

1. Clone the repository.
2. Create and activate a virtual environment.
3. Install the required dependencies.
4. Run the application using the instructions configured in the project.

## Purpose
To demonstrate lead scoring, qualification workflows, and Python application development.
